## 3. 口径与方法（可审计）

### 3.1 机构基线 vs 交叉校验
服务端快照中**只有澳门胜平负带逐点时序**，因此：
- **机构通道基线 = 澳门即盘**（唯一有形态学序列、逐 T 变动可追溯）
- **Pinnacle 即盘 + 全 319–371 家最高/最低价** 作交叉校验（V5 跨市场分歧 / 修正35 机构 Max 分歧）
- 两套基线**分别独立跑 calc_all.py**，方向结论逐场比对（19/19 双基线均已产出）

### 3.2 O2.5 折算
亚洲 2.5/3、3/3.5 等为四分之一球线（half-win / half-loss），直接二元去水会系统性偏差。
统一由 scripts/tmp/ou_from_asia.py 按 **EV 中性反解 λ_total** → 折 2.5 档 P(over) → --o25 / --u25。
例：勒沃库森 vs 弗赖堡 澳门 3/3.5 线 → λ_total 3.658 → O2.5 = **1.414**（大球强档）。

### 3.3 符号约定
- handi < 0 = **主队让球**（如 尤文 −0.75、勒沃库森 −1.00）
- handi > 0 = **主队受让**（如 诺丁汉森林 +1.00、昂热 +0.50）
- 🔴 **受让场禁设主胜比分锚**（case210 铁律）——本批 handi>0 的 **8 场**（兹沃勒+0.5 / 佛罗伦萨+0.25 / 昂热+0.5 / 格罗宁根+0.5 / 洛里昂+0.5 / 门兴+0.25 / 诺丁汉森林+1.0 / 马拉加+0.25）方向全部为客胜或客胜并列平，**未设任何主胜锚**，已遵守

### 3.4 本批两处口径纠偏（重要）

**(1) 「可单押」判定必须双条件，脚本只判了一个**
calc_match 输出的「✅强共识场(skew≥200%) → 市场首选命中 64.6% → 可单押」**只检查了 skew**。
项目铁律（AGENTS §Step5 单押准入纪律，227495 场时间分割回测）要求 **skew ≥200% 且 最低赔 <1.30 同时满足**。
本批 5 场触发脚本的「可单押」行（古比斯 1.48 / 勒沃库森 1.50 / 诺丁汉森林 1.45 / AC米兰 1.60 / 尤文 1.48），**最低赔全部 ≥1.30** → 一律判 **不通过单押准入 → 强制 2 向覆盖**（默认覆盖 = 最低赔 + 次低赔）。

**(2) 脚本「主锚建议」只作素材：本批 12/19 场主锚被改写，7 场沿用脚本主锚（但次锚仍按规则调整）**
脚本 Top1 锚在**大球强场**普遍给 1:1（2 球），同时违反两条 L2 规则：
- 锚-市场一致性：大球强（O2.5 <1.70）→ 主锚总进球 ≥3，平局只允许 2:2 / 3:3，**禁 1:1**
- 锚-市场期望铁律：主锚总进球不得低于市场期望 1.0 球以上
→ 已在每场「锚修正留痕」注明原建议与修正理由，**未机械照搬脚本 Top1**。

### 3.5 V6 盘口联动（硬门）
19 场中 **18 场末点距开赛 >180 分钟**（196–2586 分钟） → V6 四象限/剪刀差/卡位/退盘 **一律不引用**（不是「不显著」，是「前提不成立」）。
