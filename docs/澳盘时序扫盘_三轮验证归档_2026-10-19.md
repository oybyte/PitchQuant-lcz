## 0. 一句话结论

**三版方案越改越严谨，结论越清楚：亚盘时序无法稳定预测「亚盘赢盘」。**

唯一反复出现的弱信号（亚盘走势对**胜平负方向**约 +9pp 区分力，集中在中档）在严格的亚盘跟随得分口径下消失，且 A/B 分源均未通过 0.05。**登记为前瞻假设，不做成规则。**

## 2. 三版方案演进与实测

### 2.1 v0.1《量化裁决法》—— 断言式规则

**做法**：4 个"盘稳水动/盘水联动"模式 + 凯利/市场一致率卡口，承诺亚盘赢盘 58–62%。

| 断言（亚盘赢盘） | n | 实测 | 判定 |
|:--|--:|--:|:--|
| 模式1 主水强单调升≥0.08 → 客赢盘 | 12 | 41.7%（实际主赢58.3%） | ❌ **方向反** |
| 模式2 客水强单调升≥0.08 → 主赢盘 | 22 | 59.1% | ⚠️ 边缘（基线50.8%） |
| 模式3 盘水同向 | 41 | 58.5% | ⚠️ 边缘 |
| 模式4 升盘+主水升(诱)→客赢盘 | 48 | 45.8% | ❌ 随机 |

致命问题：阈值（0.08/3%/0.85/70%）全为无数据支撑的断言；用未赛的蒙扎场做"成功演示"（循环论证）；用 `1/净水位` 当全赔率（公式错误，幅度放大）。

### 2.2 v0.9《原型验证版》—— 修正为假设框架

**改进（全部正确）**：净水位改 `1+水` 全赔率；要求 Pinnacle 独立源（禁止同源）；472 场全部列开发集；删除胜率承诺；半赢半输 0.5/0.75 折算。

**实测**（一级卡口，浅盘中档 S∈[45,55%]，295 场）：

| 组 | n | 跟随得分 |
|:--|--:|--:|
| 通过一级（严格单调+|ΔS|≥2.5pp） | 24 | 0.469 |
| 排除组基线 | 271 | 0.524 |
| 差 | | **−5.5pp（负）** |

内部主/客不对称：信号→主 12.5%（n=12）vs 信号→客 81.2%（n=12）。
二级/三级卡口因 Pinnacle 无逐点时序，**0 场可执行**。

### 2.3 v1.1《预登记版》—— 方法论最严谨，自我否决

**改进**：定义 S 价格指数（不称概率）；明确 G0 适用范围；主假设用 Welch/bootstrap 单侧检验；预登记冻结机制；无效性停止规则；样本量按连续变量重估。

**§5 冻结前必做结果：**

| 必做项 | 结果 |
|:--|:--|
| #1 用 1+水 重算 472 场 | ✅ |
| #2 找有效区间写死 G0 | 🔴 新口径无有效区间 |
| #3 估计 σ | **0.459**（方案假设 0.42） |

**主假设检验（bootstrap 1 万次，种子 42）：**

```
G0=[45,55)  适用241  通过21  对照220
通过组跟随得分 0.393  对照组 0.530  差 −0.137
5% 单侧下限 = −0.296   → 下限 ≤ 0，主假设不成立
```

G0=[50,60)（旧结论档）：通过 0.604 vs 对照 0.634，差 −0.030，同样不成立。

**按方案 §8 自己的规则（点估计<0 且上限<+3pp 即停止）→ 现在就满足停止条件。**

## 3. 唯一未被否决的弱信号（登记为前瞻假设）

### 3.1 信号内容

在**胜平负口径**（非亚盘赢盘）下，市场隐含 P∈[50,60) 档：

| 亚盘走势 | n | 胜平负命中 |
|:--|--:|--:|
| 与初盘热门同向 | 43 | **79.1%** [64.8–88.6] |
| 逆向 | 32 | 46.9% [30.9–63.6] |
| 差 | | **+32.2pp，p=0.002** |

阈值稳健：[50,60)/[52,60)/[50,58) 各档 p=0.002/0.007/0.007。

### 3.2 为什么不能直接采信

1. **分源未通过**：A 组 +8.3pp（p=0.059）、B 组 +12.7pp（p=0.150），单组都不显著，仅合并 p=0.030
2. **仅在 [50,60) 一档成立**：[0,50)、[60,70)、[70,100) 差值均 ≤2pp
3. **亚盘结算口径下消失**：跟随得分 0.604 vs 0.634（v1.1 已证）—— 它预测"谁赢"，不预测"赢不赢盘"
4. **可能是多重比较产物**：扫了 10+ 切分后找到，n=43/32 偏小
5. **机制上**：与 favourite-longshot bias 同源，赔率本身可能已部分定价

### 3.3 前瞻复验协议（数据到位时直接执行）

**触发**：新一批比赛（建议 ≥150 场满足 G0 适用范围）。

**步骤：**
1. 仅取市场去水隐含最高概率 ∈ [50%,60%) 的场次
2. 用澳门亚盘逐点时序算 `Δp`（亚盘隐含概率，`1+水` 口径），`|Δp|≥1pp` 才算有方向
3. 同向 = (Δp>0 且热门=主) 或 (Δp<0 且热门=客)；反之为逆向
4. 比较同向组 vs 逆向组的**胜平负**命中率（不是亚盘赢盘）
5. 判定：两组差的 bootstrap 5% 单侧下限 > 0，且方向与 +32pp 一致 → 假设确认

**注意**：禁止用同批数据既选区间又验证（v1.1 已固定区间为 [50,60)，不得重新挑）。

## 6. 方法论教训

1. **"判方向"和"判赢盘"是两个问题**：胜平负 79% 的信号，亚盘跟随得分可能只有 60% —— 半赢/走水会吃掉全部优势
2. **过滤器必须用自己的结算口径检验**：v0.1/v0.9 用胜平负直觉设计、却声称亚盘赢盘率
3. **直觉方向可能系统性不对称**：澳门主队水位变化与客队携带的信息不同（本地主队偏好）
4. **预登记的价值**：v1.1 之所以能干净地自我否决，正因为它先固定了假设和停止规则
5. **数据源决定可检验性**：再严谨的多源设计，如果只有一个机构有时序，也无法执行
