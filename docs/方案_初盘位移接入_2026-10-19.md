## 0. 先纠正上一轮的一个结论

上一轮我说「改变了主意该避雷，坚定了主意可加仓」。**后半句对，前半句不成立。**

用同一批 441 场按「初盘热门方向的隐含位移」分档（不分加仓/弃仓）：

| 位移 | n | 热门命中 |
|:--|--:|--:|
| 弃仓 ≥5pp | 23 | **69.6%** |
| 弃仓 3–5pp | 30 | 53.3% |
| 稳定 ±3pp | 246 | 55.3% |
| 加仓 3–5pp | 57 | 61.4% |
| 加仓 5–7pp | 26 | 69.2% |
| 加仓 ≥7pp | 38 | **78.9%** |

加仓 vs 弃仓：**75.0% (n=64) vs 69.6% (n=23)，p=0.237 —— 无显著差异**。

🔴 **所以这不是「方向」信号，是「强度」信号**：只要初盘到即盘发生了大幅位移（无论朝哪边），
这场的热门方向就更准。真正的机制不是「庄家确认了某个方向」，而是
**「有大量新信息进场，把定价重新洗了一遍」**——洗过之后的价格，比死水盘口更有信息量。

## 1. 顺带发现的真问题：D1 规则没有得到数据支持

项目现有的 **D1**（`calc_match.py:775`）：*主方向升赔 ≥2 时点 累计 >3% → 触发硬降级检查*。

用 441 场真初盘重测：

| 口径 | n | 热门命中 | 95%CI |
|:--|--:|--:|:--|
| 初盘热门基线 | 441 | 58.5% | — |
| **D1 触发（升赔 >3%）** | 67 | **55.2%** | 43.4–66.5 |
| 升赔 1.5–3% | 48 | 52.1% | 38.3–65.5 |
| 稳定 ±1.5% | 165 | 56.4% | 48.7–63.7 |
| 降赔 1.5–3% | 40 | 50.0% | 35.2–64.8 |
| **降赔 >3%** | 121 | **68.6%** | 59.9–76.2 |

- D1 触发 55.2% vs 其余 59.1%，差 −3.9pp，**p = 0.277（不显著）**
- 用原始 tl 时序（与 calc_match 同源）重测：触发组 58.1% vs 未触发 57.7%，差 +0.4pp，**方向相反**

🔴 **这不是说 D1 该删**——D1 的原始依据是 case42/44 的实战教训，且它只用于「降档」这种保守动作，
错判的代价不对称。但它**确实没有大样本证据支撑**，现状是「宁可错降，不可漏降」的启发式。

→ 建议：**不改 D1**，但把它的档案改成「启发式·未经大样本验证」，
并在 `learned_rules.json` 里登记本次否定结果，防止后人误以为它有 441 场背书。

## 2. 建议接入的规则：S4「位移强度」

### 2.1 规则定义（口径必须写死）

```
基准点 = 澳门(Macauslot) 欧赔行的 init_home/init_draw/init_away   ← 真初盘
终点   = 同一行的 live_home/live_draw/live_away                    ← 抓取即盘

fav      = 初盘三项里赔率最低的方向
conc_pp  = (1/live[fav] - 1/init[fav]) * 100        ← 热门方向的隐含概率变化
fav_kept = argmin(init) == argmin(live)              ← 热门是否未变
```

🔴 **两个必须遵守的口径细节**（我第一版就写错了）：
1. 必须按**热门方向**算位移，不是「主客两个方向的绝对值取最大」
2. 位移强度用 |conc_pp|，**不分正负**

### 2.2 触发与动作

| 条件 | 动作 | 依据 |
|:--|:--|:--|
| `fav_kept` 且 **|conc_pp| ≥ 5** 且 即盘热门 < 70% | **置信 +1 档** | n=87 · 73.6% vs 55.3% · p<0.0001 |
| `fav_kept` 且 |conc_pp| ≥ 5 且 即盘热门 ≥ 70% | **不追加** | 该档稳定组已 85.7%，增量仅 +4.3pp |
| **不满足 `fav_kept`**（热门被推翻） | **−1 档 + 强制并列** | n=21 · 33.3% vs 59.8% · p=0.0082 |
| |conc_pp| 3–5 | 仅记录，不动作 | 53.3–61.4%，与基线无差 |

### 2.3 严格性证据

| 检验 | 结果 |
|:--|:--|
| 时间分割（前半） | 大位移 70.6% vs 稳定 53.3%（+17.3pp） |
| 时间分割（后半） | 大位移 75.5% vs 稳定 57.7%（+17.8pp） |
| Bootstrap 4000 次 | 实测 +0.183，95%CI **[+0.068, +0.291]**，P(≥0)=0.9990 |
| 事前变量匹配（初盘热门 ±2pp 配对） | 87 组配对，平均差 +0.106，CI **[+0.016, +0.191]**，P(≥0)=0.988 |
| 控制即盘热门概率 | 三档内一致（+8.9 / +13.7 / +4.3pp），仅 60–70% 档打平 |

🔴 **唯一弱点**：60–70% 档增量打平（77.8% vs 79.4%），说明在「中强热门」这档信号最弱。
这也正是 `fav_kept` 之外还要看 `即盘热门` 的原因——**强热门场不需要额外确认，它本来就准**。

## 3. 落地改动清单

### 3.1 P0 —— 让真初盘进决策链（当前完全没有）

在 `market_consensus` 段之后加一段输出：

```
【位移强度(S4·2026-10-19)】
  🔴初盘→即盘 热门方向位移: 客胜 −7.9pp（初盘 48.5% → 即盘 56.4%）
     → |位移|≥5 且热门未变 → 强度信号 · 本档即盘热门 48.5% < 70% → ✅ 可 +1 档
     ↳ 回测 n=87: 73.6% vs 稳定组 55.3% (p<0.0001) · Bootstrap CI [+0.068,+0.291]
     ↳ 🔴 只加标签·不改方向·不覆盖 L2 硬核
```

**为什么不能直接在 calc_match 里算**：calc_match 吃的是 txt 时序，txt 的首点是
「抓取时刻能回溯到的最早点」，不是真初盘（历史语料里 55% 不等）。
真初盘只存在于快照的 `init_*` 字段。

🔴 **不过要注意一个反例**：今日 51 场快照里，txt 首点与真初盘 **100% 一致**
（主队隐含差中位数 0.00pp）。因为服务端出的 `euro_timeline` 首个点就是 init 值。
所以「伪初盘」问题是**历史语料（matches-*）特有的**，2.5.9 快照没有这个问题。
→ 修的时候两套数据要分开处理，不能一刀切。

**最省事且无歧义的方案**：`v259_ingest.build()` 里已经有 `base_init`（真初盘）和 `base_live`，
直接多写一行：

```
🔴初盘→即盘位移：热门=客胜 · 48.5% → 56.4% (+7.9pp) · 热门未变
```

calc_all 解析这行即可，零新增数据依赖。

### 3.2 P1 —— 三次失败留下的「口径守卫」

本次我连续踩了三个坑，都值得写成断言：

| 坑 | 守卫 |
|:--|:--|
| `a_p_o − o_h` 相减不同量纲（覆盖率概率 − 胜率） | `assert` 两个概率的定义域一致才能相减；交叉特征只允许「同定义」相减 |
| 亚盘原始盘口符号与项目 handi 相反 | `line_val` 文档里写死，且转换处一律 `handi = -line` |
| 用「即盘热门概率」做控制变量（事后变量） | 分层/匹配必须用**事前**变量（初盘热门概率） |

第三条最隐蔽：我用即盘热门分层时，大位移的增量看起来只有 +0.9pp（几乎消失）；
换成初盘热门分层，增量立刻回到 +12~+18pp。**这是典型的「控制处理后变量」错误**，
它会系统性抹掉真实效应。

### 3.3 P2 —— D1 档案降级为「启发式」

`learned_rules.json` 新增：

```json
"d1_heuristic_only": {
  "status": "已证伪(大样本)",
  "evidence": "441场真初盘: D1触发55.2%(n=67) vs 未触发59.1%(n=374), p=0.277 不显著; tl时序口径方向相反",
  "rule": "D1 保留为保守启发式(降档成本不对称)·禁止当作已验证规律引用"
}
```

| 场次 | 原预测 | S4 信号 | 处置 |
|:--|:--|:--|:--|

说明它还不是稳定规律。**先跑 2-3 批实盘观察，再决定是否接入判定。**

## 6. 一句话总结

> 真正有用的不是「庄家看好谁」，而是**「这场盘口被动过没有、动得多不多」**——
> 动过的盘口更有信息量，没动过的盘口（无论看起来多稳）只是没人愿意下注而已。
>
> 而项目现在用的 `calc_match` 位移，起点是「抓取时刻能回溯到的最早点」，
> 在历史语料里 55% 是伪初盘（2.5.9 快照则 100% 正确，两套数据要分开修）。
> 更要紧的是：**位移目前只喂给 D1（一条降档启发式），从未被当作独立的强度信号用过。**
